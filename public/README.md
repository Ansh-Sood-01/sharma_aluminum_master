# Public assets

- `icon.svg` is the business-monogram favicon used by the website.
- Use this folder for approved static brand assets only.
- For portfolio photographs and videos, prefer Cloudinary uploads from the private admin dashboard so the media records can be associated with a category/project and published in the gallery.
- `src/config/gallery.ts` contains clearly labelled external inspiration/reference visuals. They are not represented as completed customer projects; replace them with the business's own photographs or keep the reference notices visible.
