# Portfolio galleries

- `GalleryExperience.tsx`: category-specific image/video viewer, zoom/pan, fullscreen, keyboard navigation, sharing and enquiry links.
- `PublishedProjectsGrid.tsx`: published project cards backed by Supabase records.
- `src/app/[locale]/gallery/[category]/page.tsx`: the dedicated route for each of the ten seeded categories.
- `src/app/[locale]/project/[slug]/page.tsx`: detail route for an individual published project.

The static references in `src/config/gallery.ts` are demo inspiration, not claims about completed company work. Add actual photos/videos from the private admin dashboard.
